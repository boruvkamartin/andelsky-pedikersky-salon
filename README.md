# Andělský pedikérský salón

Ukázkový statický web pro Andělský pedikérský salón v Trutnově.

## Lokální spuštění

Web nevyžaduje build ani závislosti. Stačí spustit lokální HTTP server, například:

```powershell
python -m http.server 4173
```

Potom otevřít `http://localhost:4173`.

## Obsah k potvrzení před ostrým spuštěním

- správné číslo domu (ve veřejných zdrojích se objevuje Bulharská 58 i 59),
- aktuální ceny a otevírací doba,
- nabídka a podmínky dárkových poukazů,
- nahrazení ilustračních fotografií reálnými fotografiemi salonu,
- finální texty a případné příspěvky zdravotních pojišťoven.
