# Andělský pedikérský salón

Statický web pro Andělský pedikérský salón v Trutnově.

## Lokální spuštění

Web nevyžaduje build ani závislosti. Stačí spustit lokální HTTP server, například:

```powershell
python -m http.server 4173
```

Potom otevřít `http://localhost:4173`.

## Zdroje veřejných údajů

- [Notino Salony](https://www.notino.cz/salony/andelsky-pedikersky-salon/)
- Podklady majitelky salonu (logo, ceník a certifikáty)
